# CareerConnect — Online Job Portal

A responsive online job portal built using HTML, CSS, JavaScript, and SQL.

## Live Demo

Visit the website: [Open CareerConnect](YOUR-GITHUB-PAGES-URL)

## Features

- Browse sample job listings
- Search jobs by title, company, or skills
- Filter jobs by location and job type
- Submit a demo job application
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- MySQL

## Database

The `database.sql` file contains tables for users, companies, jobs, and applications, along with example SQL queries.

## Project Status

The front-end demo is published using GitHub Pages. The SQL schema is provided separately; the website is not yet connected to a backend database.
